Getting started

  1. Get the workshop files from GitHub. Keep the folder structure.
  2. Open nora_uq_workshop.Rproj in RStudio, then run 00_setup.R. Use R 4.2 or newer.

The exercises use included predictions and run offline with base R. Choose whether to fill the marked lines or run the worked solutions. Both routes ask you to interpret the results.

What are we measuring?

SummaryQuestion
Prediction intervalWhat could a future house sale price be?
Ensemble SDHow sensitive is the fitted median to the sampled training data?

Exercise 1: prediction intervals

Slides 14–16 · 20 minutes in pairs

Open 01_intervals.R, or run the complete solution:

source("solutions/01_intervals_solution.R")
  • Predict what “90% coverage” should mean.
  • Calculate coverage and mean interval width for all 586 test houses.
  • Inspect the plot. How useful are these ranges for a buyer?

Bring back: both numbers, one finding and one question.

Coverage: the fraction of observed prices inside their intervals. Width: the upper endpoint minus the lower endpoint.

Calibration demonstration

Slides 17–19

Predict whether the intervals will widen or narrow. Camilla will run 03_calibration_demo.R; you can follow along. The adjustment uses reserved calibration sales, then evaluation uses test sales.

Conformal calibration targets overall coverage under exchangeability of calibration and future cases. Subgroups and changed markets need separate checks.

Exercise 2: ensemble SD

Slides 23–25 · 20 minutes in pairs

Open 02_refits.R, or run the complete solution:

source("solutions/02_refits_solution.R")
  • Compare refits using 300 and 1,500 sampled training rows.
  • Summarize the house-specific SDs and count houses with lower SD at 1,500 rows.
  • Discuss what the fits could all miss together.

Each SD describes 20 whole-forest median predictions for the same house. Rows are resampled with replacement from one training pool.

Bring back: the two median SDs, the fraction with lower SD, one finding and one question.

Optional exploration

  • 04_model_assumptions.R: explore slide 29 using a Bayesian model. Change the sample size, assumed noise or model shape. All code is supplied.

Different UQ summaries answer different questions. An explicit aleatoric–epistemic split requires modelling assumptions.

For your own research: which summary would help, what would it tell you, and what would you check?
